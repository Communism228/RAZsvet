# Отчёт о проверках версии 0.3

Дата подготовки: 7 ноября 2026 года. Результаты относятся к включённым исходникам
и скомпилированной автономной Canvas-версии, а не к любому возможному будущему изменению данных.

## Среда
- Node.js 22.16.0.
- TypeScript 5.8.3.
- Chromium 144.0.7559.96, Linux, headless, Python Playwright.
- Strict TypeScript, ES2022.

## Успешно выполнено

### Статическая проверка и сборка
```
tsc -p tsconfig.native.json
node scripts/check-assets.mjs
node scripts/standalone.mjs
tsc -p tsconfig.model.json
node --test tests/model.test.mjs
```

Общий код, модель, UI и Canvas-адаптер компилируются без ошибок.
Проверены наличие 58 ресурсов/конфигураций и размеры связанных изображений шести регионов.
Готовая папка standalone/ не требует npm-пакетов или внешней сети во время игры.

### 44 теста модели
Проверены матрица и удаления, напряжения, ограничение длины, нетранзитные потребители и источники,
направленность и КПД трансформатора, равный процент снабжения, циклы, несколько источников,
потери и энергетический баланс, ограничения строительства, маски, покупки и возвраты,
доход, пауза, дедлайн, сохранение, закрытые области и победа.

Для 25 seed проверено размещение потребителей в шести регионах.
Автоматическая эталонная стратегия завершает шесть этапов подряд, оплачивает реальные
покупки и кабели, учитывает игровое время на действия и при необходимости ждёт доход.
Это доказывает осуществимость одной стратегии для проверенной кампании, но НЕ хороший
человеческий темп, идеальный баланс или проходимость всех возможных пользовательских карт.

### 24 браузерных сценария
```
python tests/browser-smoke.py /path/to/test-artifacts
```

Используются настоящий скомпилированный App, модель, обработчики мыши/клавиатуры, painter,
HTML/CSS и реальные SVG/PNG из проекта. Проверены:
- Меню, последовательное проявление, отдельный pixel-test прозрачных полнохолстовых панелей.
- Hover городов, переход к уровню и настоящие растровые маски.
- Покупка и сборка мышью сети ВН -> трансформатор -> НН -> деревня.
- Ошибочные подключения и перекрытия без списания денег, недопустимый демонтаж.
- Переключение опор, возврат денег, матрица и инспектор.
- Пауза, справка, потеря фокуса, ограничения камеры.
- Два запитанных завода, отсутствие обязательного завода под нижним доком.
- Размещение UI при 1440x900, 1280x800 и 960x640.
- Восстановление состояния, поражение, освещение/закрытие региона, перенос денег.
- Редактор баланса и отсутствие необработанных исключений.

В среде Chromium запрещена навигация на URL политикой окружения. Политики НЕ изменялись.
Поэтому сценарии загружали скомпилированные модули через import map на about:blank,
изображения/JSON — из встроенных байтов, а localStorage — через тестовый объект в памяти.
Это не ручной интерактивный проход, не проверка настоящего HTTP origin и не проверка
постоянства localStorage после настоящей перезагрузки браузера.
Снимки интерфейса получены из этого прогона.

### HTTP-раздача
Node-сервер scripts/serve.mjs проверен отдельно HTTP-клиентом:
все 75 файлов standalone/ вернули HTTP 200 и байты, совпадающие с файлами на диске.
Это проверка путей/раздачи, не браузерной навигации.

## Не проверено в данной среде

- npm install и создание package-lock.json: npm registry недоступен.
- Полная сборка Vite и проверка типов/запуск Phaser 4.2.1.
- Phaser-хост через CanvasTexture: его присутствие в исходниках не означает успешного запуска.
- Настоящий localStorage после HTTP-перезагрузки и независимые браузерные профили.
- Firefox/Safari, мобильные устройства, старые интегрированные GPU.
- Субъективное звучание WebAudio-эффектов на реальном аудиоустройстве.
- Баланс с участием нескольких живых игроков.
- Будущая графика художников и её содержательное совпадение с масками.

## Что проверить на машине команды
1. Запустить node scripts/serve.mjs, построить небольшую сеть, обновить страницу.
2. Убедиться, что казна, время и сеть восстановились, регион на паузе.
3. Выполнить npm install, npm run check, npm test, npm run build.
4. Проверить итоговую dist/ либо standalone/ на выбранном хостинге и в целевом браузере.
5. После замены графики выполнить check:assets и пройти все шесть регионов с реальными масками.
6. При изменении баланса начать новую кампанию.
