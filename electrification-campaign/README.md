
# План света — электрификация Беларуси
## Кампания 0.3 / исходники + автономная сборка

Это самостоятельная версия прототипа. Распакуйте в НОВЫЙ каталог, не поверх старого.
Все карты и изображения здесь — временные примитивы. Границы областей, месторождения и участки
условны; это не историко-географическая реконструкция.

## Запуск без установки npm-пакетов

```bash
cd electrification-campaign
node scripts/serve.mjs
```

Откройте `http://127.0.0.1:4173`. Сервер раздаёт уже включённый каталог `standalone/`.
Нужен установленный Node.js. Доступ к интернету для этой сборки не нужен.
Не открывайте index.html через `file://`.

Сервер предназначен только для локального просмотра, слушает 127.0.0.1.
Можно изменить порт: `PORT=4174 node scripts/serve.mjs`.

## Разработка

```bash
npm install
npm run dev
```

Vite выведет HTTP-адрес, обычно `http://localhost:5173`.
`package-lock.json` не включён: среда подготовки не смогла связаться с npm.
Первая установка создаст lockfile; зафиксируйте его в Git. После этого для воспроизводимых
установок используйте `npm ci`.

```bash
npm run check:native      # строгая проверка общего кода + Canvas
npm run check:assets      # наличие ресурсов и размеры совмещённых изображений
npm test                 # чистая модель: электричество, деньги, этапы, сохранения
npm run check            # включает также типы опционального Phaser-адаптера
npm run build            # Vite: результат в dist/
npm run preview          # локальная проверка dist/
npm run build:standalone # обновить standalone/ после изменения кода или public/
```

**По умолчанию используется Canvas 2D.** Эта версия проверена и включена в архив.
В проекте сохранён отдельный Phaser-адаптер, использующий тот же расчёт, отрисовку и интерфейс.
После установки зависимостей он включается адресом `http://localhost:5173/?renderer=phaser`.
Это совместимый хост через CanvasTexture, а не отдельный набор Phaser-сцен или нативный sprite tree.
Полная установка npm, сборка Vite и запуск Phaser в среде подготовки не выполнялись.
Не считайте этот адаптер проверенным только потому, что проверен Canvas.

Зафиксированы Phaser 4.2.1, Vite 8.3.6 и TypeScript 5.8.3.
Для инструментов используйте Node.js 22.12 или новее.

Для хостинга загрузите содержимое `dist/` либо готового `standalone/`.
`index.html` должен лежать в корне публикуемого ZIP, а не внутри лишней папки.
Пути относительные, поэтому возможна публикация в подпапке сайта.

## Что реализовано

Меню с движущимся фоном и большой кнопкой «Играть» → вступление, в котором панели плавно
появляются на одной странице → выбор одного из шести регионов → приближение и затемнение →
региональная игра → проверка плана → освещение и блокировка области или поражение.
После шести выполненных этапов появляется победа.

Вступление листается кликом / пробелом / Enter. Первый клик во время проявления сразу завершает
текущую анимацию, следующий показывает новую панель. Есть пропуск.

На регион: один город, четыре деревни, два завода. Подготовленные точки случайно смещаются
с воспроизводимым seed; проверяются вода, запреты, строительные основания, месторождения и
пересечения. Это управляемая случайность, а не равномерный разброс по всей карте.

Угольная ТЭС ставится внутри угольной зоны; торфяная — внутри торфяной.
ГЭС проверяет центральную точку по hydro-mask. Обычные здания, опоры и трансформаторы —
на суше. Кабели могут проходить над водой. Их пересечения не образуют узел.
Топливо не расходуется; карта месторождений задаёт только пригодность места.

Размер мира 20 000 × 12 500 метров. Видимый размер зданий условен.
Расстояния и сопротивление считают по координатам центров в метрах, не по пикселям.
Камера масштабируется до 1.65 и сдвигается не более чем на 14% размера карты от центра;
при минимальном масштабе весь игровой участок вписан в окно.

## Управление

| Клавиша | Действие |
|---|---|
| 0 | Выбор здания / кабеля |
| 1 | Угольная ТЭС |
| 2 | Торфяная ТЭС |
| 3 | ГЭС |
| 4 | Трансформатор |
| 5 | Опора |
| 6 | Кабель, два клика |
| 7 | Демонтаж |
| V | Переключить ВН / НН для новой опоры |
| M | Показать / скрыть матрицу |
| Esc | Закрыть панель, отменить кабель либо пауза |
| Delete | Удалить выбранное своё здание / кабель |
| Колесо, +, − | Масштаб |
| Средняя кнопка мыши или пробел + перетаскивание | Передвижение камеры |
| Home | Центр и исходный масштаб |

У трансформатора вход ВН слева, выход НН справа. Нажимайте на соответствующую половину.
Клик по тому же зданию отменяет незаконченный кабель. Правая кнопка также отменяет его.
Shift при завершении кабеля на опоре оставляет её началом следующего участка.

Заводы и населённые пункты нельзя удалить или купить.
При демонтаже своей постройки возвращается 50% её фактически оплаченной стоимости и стоимости
удаляемых вместе с ней кабелей. Отдельный кабель возвращает 50% своей цены.
В кампании нет отката времени или казны через Undo.

## Первая работающая сеть

1. Угольная ТЭС внутри отмеченной зоны угля.
2. Трансформатор рядом с деревней, но не поверх неё: ориентир 1.0–1.2 км.
3. Кабель от станции к ЛЕВОЙ стороне трансформатора.
4. Кабель от ПРАВОЙ стороны трансформатора к деревне.

Если магистраль длиннее 3.8 км, добавьте высоковольтную опору.
Низковольтный участок ограничен 1.6 км: для него нужна опора НН либо более близкий трансформатор.
Станцию нельзя подключить непосредственно к дому или заводу: напряжение не совпадёт.

Питаемая деревня приносит 1.3 ₽/с, город — 2.4 ₽/с.
Ранний доход финансирует линии к заводам. Не обязательно освещать все поселения для победы:
обязательны оба завода. Дополнительные потребители делят доступную мощность с заводами,
поэтому перед их подключением проверьте запас.

## Электросеть

Матрица смежности — ЕДИНСТВЕННЫЙ источник топологии. Ненулевая ячейка хранит длину кабеля
в метрах; нуль означает отсутствие кабеля; матрица симметрична, диагональ нулевая.
Тип напряжения и выбранные порты — метаданные связи, а не отдельная сеть.
В диагностической таблице длины отображаются в километрах.

Станции выдают 10 кВ; потребители принимают 400 В.
Трансформатор направленно преобразует ВН → НН, с КПД 96% и лимитом выхода 200 кВт.
Транзит чужой мощности возможен только через опоры; трансформатор — отдельное направленное
преобразование. Ни станция, ни город, ни завод не являются транзитной опорой.

Распределение: одинаковый процент потребности внутри каждой группы снабжения, ПОСЛЕ потерь.
Потребитель на 24 кВт при обеспеченности 50% получает 12 кВт, завод на 130 кВт — 65 кВт.
Полностью отключённая группа не уменьшает мощность другой сети.
Для численной устойчивости порог «полное питание» — 99.9%; в UI это округляется до 100%.

Потери рассчитываются через эквивалентную модель:
`R = r * длина`, `I = Pотправлено / U`, `Pпотери = I²R`.
В программе кВт явно переводятся в Вт. Параметр r — эффективное сопротивление линии на метр,
а не паспорт конкретного реального провода.

Это стационарная модель распределения мощности, НЕ полный расчёт электрической цепи.
Нет фаз, реактивной мощности, частоты, переходных процессов и решения напряжений узлов.
Точнее о приближении и оптимизаторе: [docs/POWER_MODEL_RU.md](docs/POWER_MODEL_RU.md).

## Экономика, срок и кампания

Первый этап длится 180 секунд активного времени; последующие —
165, 150, 135, 120 и 120 секунд. Всего 14.5 минуты региональных таймеров.
Цены умножаются на `(1 + 0.08)^число_завершённых_регионов`, с округлением вверх.
Цена кабеля зависит от его длины, класса напряжения и текущего множителя.

В конце срока проверяется ТЕКУЩЕЕ одновременное питание всех заводов.
Последовательное включение разных заводов не засчитывается.
Раннее выполнение плана не завершает уровень: сеть требуется сохранить до срока.

Выполненный регион закрыт навсегда. Его накопленная казна переносится дальше,
но населённые пункты больше не производят доход. Автоматической премии нет
(`completionBonus: 0`; её можно включить в настройках).
При провале показывается: «Вы не выполнили план и отправляетесь в Сибирь».

Esc, справка, окно настроек, скрытие вкладки и потеря фокуса останавливают таймер и доход.
После возврата требуется снять паузу. Открытая матрица сама по себе время НЕ останавливает.

Сохранение в localStorage — после строительства и раз в пять секунд. «Играть» продолжает его;
активный регион восстанавливается на паузе. Сохранения прототипа 0.1 не импортируются.
При изменении баланса старое сохранение отвергается: начните новую кампанию.
Браузерное хранилище привязано к адресу сайта: localhost и 127.0.0.1 — разные адреса.
Эта особенность поведения стандартного браузера; сохранение не синхронизируется между устройствами.

## Настройка баланса

Главный файл — `public/data/balance.json`: цены, мощности, доход, срок, рост сложности,
сопротивление, максимальная длина и ток линий, размеры условных площадок и ограничения камеры.
Положение ресурсов и точки генерации — `public/data/regions/*.json`.
Надписи надсмотрщика и интервалы — `public/data/messages.json`.

Для панели настройки откройте `http://127.0.0.1:4173/?dev=1`
или добавьте `?dev=1` к адресу Vite. Нажмите «БАЛАНС» на карте страны / «DEV» в регионе.
Есть основные численные поля и полный редактор JSON.
«Применить» начинает НОВУЮ кампанию с тем же seed — это удобно для сравнения настроек.
Экспортируйте JSON и замените исходный `public/data/balance.json`, иначе изменения
действуют только до перезагрузки страницы. Для standalone затем выполните пересборку.

Баланс прошёл автоматическую проверку эталонной стратегии на шести этапах с реальной казной
и временем на каждую операцию. Это проверка осуществимости одной стратегии, а не законченный
игровой баланс, оценка человеческого темпа или гарантия любой случайной раскладки.

## Как заменить графику

Подробная инструкция: [docs/ASSETS_RU.md](docs/ASSETS_RU.md).
Быстрый путь: PNG в `public/assets/`, соответствующий путь в `public/data/assets.json`.
Ни расчёт электросети, ни цены менять для этого не нужно.
Для отдельных иконок дока предусмотрено поле `icon`; для состояний — `idle` и `powered`;
для кадровой анимации — `frames`.
Текст, цены, таймер и диалоги не запекайте в изображения.

## Структура исходников

- `src/model/types.ts` — форматы данных и типы.
- `src/model/terrain.ts` — маски, проверка площадок, случайный генератор.
- `src/model/world.ts` — здания, матрица и кабели.
- `src/model/simulation.ts` — стационарное распределение и потери.
- `src/model/simplex.ts` — небольшой оптимизатор без зависимостей.
- `src/model/campaign.ts` — покупки, казна, время, этапы, сохранения.
- `src/assets.ts` — загрузка графики и декодирование масок.
- `src/app.ts` — переходы между экранами, ввод и HTML-интерфейс.
- `src/render/paint.ts` — общий код изображения игры.
- `src/render/native.ts` — основной Canvas-хост.
- `src/render/phaser.ts` — опциональный Phaser-хост.
- `src/style.css` — вся палитра и интерфейс.
- `tests/` — модельные и браузерные проверки.

Сначала меняйте данные в public/, затем игровую модель, и только потом отображение.
После рабочих этапов делайте коммиты. Подробные границы проверки — в `docs/VERIFICATION_RU.md`.
