# РАЗ, СВЕТ! — 0.6.0

Полный проект: TypeScript, Canvas 2D, HTML/CSS, Vite. Готовая сборка в `standalone/`.

## Запуск

Распакуйте в новую папку. Нужен Node.js 22.12+.

```bash
cd raz-svet
npm install
npm run dev
```

Без установки зависимостей:

```bash
node scripts/serve.mjs
# http://127.0.0.1:4173
```

Не открывайте HTML через file://. Для публикации загрузите содержимое `standalone/` на статический хостинг.
Исходники редактируются в `src/` и `public/`, не в `standalone/`.

## Новое

- Заменены опора ЛЭП, кабель, демонтаж и оба состояния радио.
- Два первых срыва плана — штрафы. Третий — финал на фоне Siberia.png.
- Шкала времени увеличена без искажения пропорций.
- Окна, кнопки и подписи переоформлены в жёлто-белой палитре.
- Музыка и шрифт загружаются в настройках без пересборки.

## Музыка

В присланных вложениях не было аудиофайла. Конкретный трек не включён.
Откройте шестерёнку → Выбрать аудиофайл. Затем нажмите радио. Повторный клик останавливает музыку.
MP3, WAV, OGG, M4A и другие аудиоформаты поддерживаются в пределах возможностей браузера. Музыка зациклена; громкость меняется в настройках.

Картинка радио зависит от наличия сообщения, а не от музыки. Значок ♫ указывает на включённый трек.

Для встроенного трека положите ваш файл в `public/assets/audio/background.mp3` и измените `public/data/assets.json`:

```json
"audio": { "background": "assets/audio/background.mp3", "volume": 0.35 }
```

Соберите проект повторно. Трек по-прежнему включается нажатием радио, не автоматически.

## Шрифт

Все текстовые стили подготовлены для Rodchenko. Бинарные файлы шрифта не включены в этот архив.
Откройте настройки → Загрузить шрифт → выберите ваш `rodchenko (1).zip`. Игра сама выберет `Rodchenko Bold.otf`.
Можно выбрать и отдельный OTF/TTF. Шрифт применяется к интерфейсу и подписям на Canvas.
Уже установленный в системе Rodchenko подхватывается через CSS local().
До загрузки используется резервный шрифт.

Локальные медиа сохраняются в IndexedDB браузера. При запрете хранилища игра сообщит об этом; файл будет работать до перезагрузки.
Другой порт, домен или профиль браузера — другое хранилище.

## Штрафы

Один срыв общего срока региона = одно нарушение, независимо от числа незапитанных целей.
Первое: 120 ₽. Второе: 180 ₽. Третье: финал в Сибири.
После первых двух нарушений нажмите «Исправить план»: даётся 120 секунд в том же регионе. Постройки, кабели, цели и ресурсы остаются на месте.
Штраф может сделать казну отрицательной. Доход погашает долг. Новые покупки по-прежнему требуют достаточного баланса.
Счётчик нарушений общий для всей кампании. Победа в области его не сбрасывает.

## Баланс

`public/data/balance.json`:

```json
"penalties": { "fine": 120, "fineGrowth": 60, "maxStrikes": 3, "retrySeconds": 120 }
```

Панель баланса доступна с `?dev=1`; применение настроек начинает новую кампанию.
Сохранения версии 0.5 не мигрируются: начните новую кампанию. Медиа хранятся отдельно от игрового прогресса.
