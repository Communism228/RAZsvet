# Как заменить ассеты позже

В проекте уже подключены финальные файлы из архива `Sprites(1).zip`.

## Что сейчас подключено
- `public/assets/country/*` — карта страны и маски регионов
- `public/assets/intro/*` — кадры интро-комикса
- `public/assets/sprites/*` — игровые спрайты и иконки
- `public/assets/overseer.png` — изображение персонажа в сообщениях
- `public/data/assets.json` — манифест путей к ассетам
- `public/data/intro.json` — порядок и показ кадров интро
- `public/data/regions/*.json` — состав объектов на региональных картах

## Если захотите заменить спрайты на новые
1. Положите новые файлы в `public/assets/sprites/`.
2. Откройте `public/data/assets.json`.
3. У нужного объекта поменяйте пути `idle`, `powered` и при необходимости `icon`.
4. Если новый спрайт визуально другого формата, поправьте параметры:
   - `width`
   - `height`
   - `anchorX`
   - `anchorY`
5. Выполните сборку:
   ```bash
   npm run build:standalone
   ```

## Если нужно заменить интро-комикс
1. Положите новые кадры в `public/assets/intro/`.
2. Обновите `public/data/intro.json`.
3. Для полноэкранных прозрачных слоёв используйте `fullPageLayers: true`.

## Если нужно заменить карту и маски регионов
1. Замените файлы в `public/assets/country/`.
2. Проверьте пути `country.dark` и `country.light` в `public/data/assets.json`.
3. Проверьте, что маски регионов (`*-mask.png`) совпадают с новыми границами.

## Важное примечание
- Для опоры ЛЭП в загруженном архиве не было отдельного финального спрайта, поэтому в проекте пока оставлен существующий спрайт опоры.
- Для деревни временно используется уменьшенный вариант городского спрайта.
