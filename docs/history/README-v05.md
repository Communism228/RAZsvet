# РАЗ, СВЕТ! — v0.5.0

Браузерная 2D-стратегия электрификации. TypeScript, Canvas 2D, HTML/CSS, Vite.
Исходники и готовая сборка в одном архиве. Нужен Node.js >=22.12.

## Запуск без npm install

```bash
node scripts/serve.mjs
```

Открыть `http://127.0.0.1:4173`. Сервер раздаёт `standalone/`.
При занятом порте: `PORT=4174 node scripts/serve.mjs`.

## Разработка

```bash
npm install
npm run dev
```

Адрес напечатает Vite. Первый `npm install` создаст `package-lock.json`: зафиксируйте его в Git.
Готовая сборка не требует сетевых сервисов, CDN или дополнительных шрифтов.

## Что изменилось

- Новое меню: фон, логотип, кнопки из `Sprites(2).zip`.
- Новый портрет, диалоговая плашка, радио, монета, шкала месяцев и док.
- У деревни и города разные спрайты, потребление и доход. В регионе 2 города, 6 деревень и 2 завода.
- Шесть регионов имеют разные вырезки карты и маски воды. Источник — векторный слой рек из `Map/dark.svg` архива. Файла `dark.png` в исходном архиве не было: он получен из SVG.
- Камера начинает с 1.7x, максимум 4x. Добавлена кликабельная мини-карта.
- Уголь и торф генерируются в случайных допустимых точках. Может отсутствовать один или оба ресурса. Регион без месторождений можно запитать через ГЭС.
- Пустые прозрачные поля убраны. Комикс вписывается в полную высоту/ширину окна без искажения. У вертикальной страницы на широком экране остаются поля по бокам: панели не обрезаются.

| Клавиша | Действие |

| 1 / 2 / 3 | Угольная ТЭС / торфяная ТЭС / ГЭС |
| 4 / 5 / 6 / 7 | Трансформатор / опора / кабель / демонтаж |
| 0 | Выбор объекта |

## Баланс и ресурсы

`public/data/balance.json`: цены, потребление, доход, физика, камера и генерация.

```json
"resources": {
  "mode": "random",
  "emptyRegionChance": 0.12,
  "coal": { "minCount": 2, "maxCount": 4, "noneChance": 0.22, "radiusM": 800 },
  "peat": { "minCount": 2, "maxCount": 5, "noneChance": 0.22, "radiusM": 850 }
}
```

`mode: "none"` — вообще без месторождений; `fixed` — использовать `deposits` из JSON региона.
`emptyRegionChance` — шанс отсутствия обоих ресурсов; `noneChance` — шанс отсутствия отдельного ресурса.
Генератор ограничен числом попыток: при нехватке суши размещает меньше точек, не зависает.
Точки сохраняются в составе активного региона. Перезагрузка не перебрасывает ресурсы.

Для панели баланса добавьте `?dev=1` к адресу. Применение начинает новую кампанию с тем же seed. Постоянные изменения — экспорт JSON и замена файла.

## Карты и иконки

Мир остаётся 20 x 12.5 км. Зум меняет только вид: длины, цены кабелей и потери не меняются.
Размеры иконок условные, не географические. Месторождения и расстановка потребителей — игровые, не историческая реконструкция.

- `public/data/assets.json` — пути к картинкам и логические размеры иконок.
- `public/data/intro.json` — общий холст комикса, порядок слоёв и плавность.
- `public/data/regions/*.json` — карты, маски, `countryCrop`, точки потребителей.
- `docs/ASSETS_RU.md` — как подменять графику.

## Сборка и проверки

```bash
npm run check:native
npm test
npm run build:standalone
```

После установки всех npm-зависимостей: `npm run check && npm run build`.
Публикация: содержимое `standalone/` либо `dist/` после Vite-сборки, `index.html` в корне.
После правки `public/` пересоберите standalone; этот каталог не обновляется от одного сохранения исходника.

Сохранения v0.4 не загружаются: карты и генерация ресурсов изменились. Ключ нового localStorage: `raz-svet-campaign-v5`.
Точный объём проверок и ограничения среды: `docs/VERIFICATION_RU.md`.
