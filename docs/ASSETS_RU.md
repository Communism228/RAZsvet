# Замена графики в v0.5

Источник: `Sprites(2).zip`. В архив игры включены оптимизированные рабочие PNG, не дубли огромных исходных холстов.
Полный журнал обрезки и размеров: `art-import-v05.json`.

## Спрайты

Положите PNG с альфа-каналом в `public/assets/sprites/`.
В `public/data/assets.json` измените `sprites.<type>.idle`, `powered`, `icon`.
Пути начинаются с `assets/`, без `public/`.
Размер файла в пикселях не определяет размер на карте: за него отвечают `width`, `height`, `anchorX`, `anchorY`.
Типы: `coal`, `peat`, `hydro`, `pole`, `transformer`, `village`, `city`, `factory`.

Если меняете логические размеры иконки, согласуйте `buildings.<type>.clearanceWidthM` и `clearanceHeightM` в `balance.json`.
При центральном якоре минимум: `width * world.widthM / 1280` и `height * world.widthM / 1280`.
Эта область отвечает за запрет перекрытия иконок. Меньшие `widthM/heightM` — основание на земле для проверки воды.
Длина кабеля всегда считается между координатами зданий, не между краями PNG.

Деревня: в исходном наборе была одна картинка; незапитанная версия — затемнённый вариант этого же рисунка. Город имеет оба авторских состояния.
Опора и кнопка домой вырезаны из вашего `UI_example.png`: отдельных PNG для них не было.
Кабель и демонтаж обозначены текстовыми знаками: в архиве нет их отдельных рисунков.

## Интерфейс

`assets.json -> ui` содержит пути к плашке, шкале, монете, логотипу и кнопкам.
`overseer` — отдельный портрет. `ui.radio` — кнопка звука, не портрет.
Размещение: `src/style.css`, блок v0.5 в конце файла.

## Комикс

7 прозрачных слоёв одинакового размера. Обрезана только общая пустая рамка, взаимное положение панелей сохранено.
Не обрезайте каждый слой отдельно, иначе панели потеряют совмещение. Новые размеры страницы укажите в `intro.json`.

## Карты

Карта страны и маски областей: 1280 x 800. Маски областей — белый силуэт с прозрачным фоном.
Карта региона и логические маски: 1600 x 1000. Логические маски — непрозрачные чёрно-белые PNG.

- `water`: вся вода.
- `hydro`: реки для точки установки ГЭС (без озёр).
- `blocked`: территория вне выбранной области.
- `spawn`: территория для потребителей; вода и перекрытия проверяются отдельно.

Белый означает наличие признака. Маски и фон должны совпадать пиксель в пиксель.
Проверка `npm run check:assets` и автоматически перед Vite.
